# v0.2.0 修改要求

以下为本轮提示词摘要。凭据已省略。

1. 照片和 PDF 点开预览后都能单独导出。
2. 接入 DeepSeek 官方 OpenAI 兼容接口和 `deepseek-flash`，使用者和测试者无需配置 AI。
3. 移除按日期自动归学期。直接选大一上、大一下等，也保留未归入学期。当前学期可作为新增记录的默认值，每条记录可改。
4. 在「新增」的名称栏上方放 AI 输入框，支持描述和证书照片识别，自动填表。
5. 支持自定义和删除类别。
6. 时间改为选填。

后续确认采用 APK 直接内置凭据的方式，用户已知晓其风险。内置凭据通过本地私有构建输入提供。源码、Git、日志和备份不保存其明文。
