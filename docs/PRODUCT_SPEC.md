# 拾证产品规范

拾证面向大学生，按经历保存综测相关材料。应用无需注册，可离线新增、查找、补充和备份。

## 记录

- 必填名称、类别。日期选填，可为单日或起止区间，结束日包含在区间内且不能早于起始日。已填写的日期可清除。
- 预置竞赛、志愿服务、社会实践、科研、文体活动、荣誉表彰、培训、其他。用户可添加或删除类别，既有记录保留已用类别。级别可空，选项为国家级、省级、市级、校级、院级、其他。
- 学期直接选择大一上、大一下至大五下、自定义学期或未归入学期。新增记录默认使用「我的 → 学期管理」设定的当前学期，也可单独改选。修改当前学期只影响后续新建记录。单位、结果、备注和混合附件可空。
- 记录页按经历起始日倒序，无日期的记录排在有日期的记录之后。支持按名称、单位和备注搜索。类别、级别、学期和归档状态可叠加。全部、待补证明、已归档为共享同一归档条件的快捷项。
- 保存记录直接生效。选填信息另页录入。编辑保留现有资料，离开有修改的录入流程前提示。
- 有附件为已归档。照片拍摄或相册导入，应用内可缩放。PDF 应用内阅读。照片、PDF 和 Word 都可以在各自的预览页另存原件，Word 也可交由兼容应用打开。附件支持改名、调整次序、删除。删除记录、删除附件各有确认，并保留外部源文件。

## 我的

提供概况、学期管理、类别管理、备份与恢复、AI 记录、AI 设置和关于。学期管理可设置或清除当前学期，也可添加或编辑自定义学期。备份与恢复使用系统文件选择器，恢复时先检查并显示替换提示，可先备份。

## AI 填写

带内置凭据的测试包默认使用 DeepSeek Flash，无需用户配置。新增页在名称上方提供 AI 输入框，接收经历描述及单张照片，允许只选图或只写描述。「我的 → AI 记录」是同一新增页的快捷入口。照片原件可随记录保存。发送前核对目标服务、模型、文字、所选照片及可用类别名称。AI 只填空白字段，用户核对后自行保存。

AI 设置提供开关、内置服务、自定义 HTTPS 接口及连接测试。用户从新增页打开设置时保留草稿。没有网络时，仍可完整使用离线功能。

不纳入账号、云同步、消息、社交、广告、学号和综测计分。期末批量导出保留程序接口。
