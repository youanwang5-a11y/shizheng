# 拾证使用说明

拾证给需要整理综测材料的大学生使用。每次经历建一条记录，证明随手补上，期末可按学期、类别或关键词查找。

**打开应用**　将拾证 APK 保存到 Android 9 或以上的手机，用文件管理器打开并安装。若手机询问安装来源，按系统提示为当前来源授权。安装后从桌面打开「拾证」。

**先记一次经历**　在「记录」点「新增」，填名称、类别和日期，再点「保存记录」。一段活动可以选「时间段」。没有附件时显示「待补证明」，单位、结果和备注可在「补充信息与证明（可选）」填写。

**补上证明**　打开记录详情，点「添加证明」，选择拍照、相册或导入文件，再保存。有一个或多个附件即为「已归档」。点击附件看照片、PDF 或 Word 操作。Word 可另存，打开它需要手机上有兼容应用。进入「管理证明」可改名、调整顺序或删除。

**找资料与换手机**　记录页可搜索名称、单位、备注并叠加筛选。到「我的 → 学期管理」设置日期范围。换手机前点「我的 → 备份与恢复 → 保存备份」。在新手机选择同一备份并确认恢复。恢复会替换本机已有资料，可先备份本机。

**需要时用 AI**　先到「我的 → AI 设置」启用并填写 HTTPS 接口、Key 与模型。回到「我的 → AI 记录」，粘贴经历文字，核对发送内容，再生成草稿。检查日期、名称和类别，点「保存记录」才会入库。无需 AI 也可完成以上所有本地操作。
