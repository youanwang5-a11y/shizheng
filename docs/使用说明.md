# 拾证使用说明

拾证给需要整理综测材料的大学生使用。每次经历建一条记录，证明随手补上，期末可按学期、类别或关键词查找。

**打开应用**　将拾证 APK 保存到 Android 9 或以上的手机，用文件管理器打开并安装。若手机询问安装来源，按系统提示为当前来源授权。安装后从桌面打开「拾证」。

**先记一次经历**　在「记录」点「新增」，填名称和类别，再点「保存记录」。日期选填，也可以选「时间段」。没有附件时显示「待补证明」，单位、结果和备注可在「补充信息与证明（可选）」填写。

**补上证明**　打开记录详情，点「添加证明」，选择拍照、相册或导入文件，再保存。有附件即为「已归档」。点开照片、PDF 或 Word 预览，可以单独另存原件。Word 也可用兼容应用打开。进入「管理证明」可改名、调整顺序或删除。

**设置学期和类别**　在「我的 → 学期管理」选当前学期，新增时会默认选中。每条记录也可以改选，例如大一上、大一下或未归入学期。到「我的 → 类别管理」添加或删除自定义类别，已有记录会保留原类别。

**找资料与换手机**　记录页可搜索名称、单位和备注，也可按学期或类别筛选。换手机前点「我的 → 备份与恢复 → 保存备份」。在新手机选择同一备份并确认恢复。恢复会替换本机已有资料，可先备份本机。

**需要时用 AI**　在新增页的「AI 智能填写」输入经历或点「选图识别」选择证书照片。私测 APK 可直接使用。点「识别并填入」，确认发送内容后核对表单，再自行保存。AI 可以在「我的 → AI 设置」中关闭。
