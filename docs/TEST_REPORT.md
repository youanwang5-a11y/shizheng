# 拾证 0.1.0 测试报告

## 环境

Windows 11 x64、Microsoft OpenJDK 17.0.21.1、Gradle 8.13、AGP 8.13.2、SDK Platform 36 rev. 2 和 Build-Tools 35.0.0。模拟器为 Android 15 / API 35 x86_64 AOSP，使用 WHPX。测试材料为合成样例。

## 已执行

| 检查 | 结果与证据 |
| --- | --- |
| Gradle Wrapper、Android 构建 | Wrapper 下载并校验 Gradle 8.13。调试、设备测试、未签名 release APK 构建通过 |
| Android Lint | `:app:lintDebug` 通过，0 错误。现有 15 条提示来自依赖更新提示和 SharedPreferences 写入风格 |
| JVM 业务规则及备份测试 | 7 项通过。验证必填、日期、学期唯一匹配、手动覆盖、组合筛选、最后一份附件移除、备份往返及格式、路径、关系与内容损坏 |
| JVM AI 协议测试 | 5 项通过。TLS 模拟服务测试请求体、已确认文字、鉴权、无效返回、超时、取消和缺失事实留空 |
| Android 存储设备测试 | 混合 PNG、PDF、DOCX 导入、分类和学期、应用内复制、重开数据库、PDF 解析、Word 另存、删除最后附件、备份校验和替换恢复通过 |
| Android 界面设备测试 | 2 项通过。无证明保存、待补筛选、搜索无结果、AI 入口及返回上下文、发送确认、鉴权失败不入库、模拟响应生成草稿与编辑保存 |
| 已签名 APK 操作检查 | Android 15 模拟器安装并启动。直接保存无附件记录，混合导入 PNG、PDF、DOCX 后转为已归档。打开照片，查看第二页 PDF。模拟器相机拍照返回原件。Word 无兼容应用提示出现，系统另存副本的 SHA-256 与原件相同 |
| 签名包备份和恢复 | 系统选择器保存备份。选择损坏文件后拒绝替换。正常备份显示数量，取消「先备份当前数据」的选择器后返回确认页。确认替换将 4 个附件恢复为原来的 3 个，PDF 可读 |
| APK 与来源 | `apksigner` 验证 v3 签名，`zipalign` 校验对齐，`aapt` 校验包名、版本、最低 API 28 与目标 API 36。APK 内 Git 信息与索引的构建提交一致 |
| 最终归档 APK | 同签名覆盖安装成功。模拟器飞行模式下冷启动，已恢复记录和 PDF 可访问。用系统相册选中照片并导入草稿。选择继续编辑后草稿保留，放弃修改后原有 3 个附件保留 |

最终机器报告在 `releases/v0.1.0/verification/`。首次校验曾因本机 SDK 路径转义、测试证书链和设备 UI 定位失败，这些问题已修正并复跑。
