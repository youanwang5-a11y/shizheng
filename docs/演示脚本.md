# 拾证三分钟演示脚本

目标时长 2 分 40 秒。用 Android 录屏展示一次从记活动到找回证明的真实过程。提前将一张合成志愿证明照片放进相册，并设好演示用学期。使用已装好的签名 APK，录屏时从桌面打开应用。

| 时间 | 屏幕操作 | 建议旁白 |
| --- | --- | --- |
| 0:00–0:18 | 从桌面打开拾证，停在记录页 | “期末整理综测时，经常知道自己参加过活动，却找不到证明。我用拾证把它们放在一起。” |
| 0:18–0:50 | 新增「图书馆志愿服务」，类别选志愿服务，选真实演示用日期，直接保存 | “活动结束先记名称、类别和日期。证明还没拿到，可以先保存，记录会显示待补证明。” |
| 0:50–1:25 | 详情点「添加证明」，从相册选合成证明，填写「服务 8 小时」并保存，打开照片并缩放 | “收到证明后补在原记录里。状态自动更新为已归档，打开就能查看原来的证明。” |
| 1:25–1:55 | 回到列表，搜索「图书馆」，选择「已归档」，展示匹配的记录 | “期末可以按关键词、学期和状态查找。这就是刚保存的经历及证明。” |
| 1:55–2:25 | 打开「我的 → 备份与恢复」，通过系统选择器保存一份备份 | “换手机前可以备份记录、学期和附件，在新手机恢复。” |
| 2:25–2:40 | 回到「我的」，展示 AI 记录和 AI 设置 | “需要从文字整理草稿时，可选配 AI。平时直接离线使用即可。” |

若要展示 AI，只有已配置并实测成功才录真实生成，把备份片段缩短以留出生成时间。录屏前后核对没有拍进凭据、私人文件或真实证书。当前文档为脚本，视频待实际录制。
