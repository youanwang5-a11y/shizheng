# 拾证三分钟演示脚本

目标时长 2 分 40 秒。用 Android 录屏展示一次从记活动到找回证明的真实过程。提前将一张合成志愿证明照片放进相册，并设好演示用学期。使用已装好的签名 APK，录屏时从桌面打开应用。

| 时间 | 屏幕操作 | 建议旁白 |
| --- | --- | --- |
| 0:00–0:18 | 从桌面打开拾证，停在记录页 | “期末整理综测时，经常知道自己参加过活动，却找不到证明。我用拾证把它们放在一起。” |
| 0:18–0:50 | 新增「图书馆志愿服务」，类别选志愿服务，保留当前学期，日期留空并保存 | “先记名称和类别就能保存。系统会带入我设好的当前学期，证明到手后再补。” |
| 0:50–1:25 | 详情点「添加证明」，从相册选合成证明并保存，打开照片，点「另存照片」 | “补齐证明后会变成已归档。点开任何一份证明，都可以单独另存原件。” |
| 1:25–1:55 | 回到列表，搜索「图书馆」，选择「已归档」，点「多选 → 全选 → 导出」，通过系统选择器保存 ZIP | “期末可以按关键词和状态查找，选中需要的记录后，把清单和证明一起导出。” |
| 1:55–2:25 | 退出多选，展示「我的 → 导出记录」的学年选项，返回并打开「备份与恢复」 | “也可以一次选中同一学年的两个学期。换手机时，在这里保存完整备份，到新手机恢复。” |
| 2:25–2:40 | 回到「记录 → 新增」，展示 AI 智能填写 | “可以描述一次经历，或选一张证书照片让 AI 填表。发送前可以核对，识别后由自己保存。” |

若要展示完整 AI 识别，使用私测 APK 与合成证明，缩短备份片段以留出生成时间。录屏前后检查私人文件和真实证书。当前文档为脚本，视频待实际录制。
