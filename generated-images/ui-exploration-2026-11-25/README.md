三套主题各自预览「记录」与「新建记录」，以便对照同一套界面。

| 主题 | 颜色与插画 |
| --- | --- |
| [黑色主题](06-theme-black.png) | 近黑底、石墨卡片、银灰小插画和浅银按钮。 |
| [白色主题](07-theme-white.png) | 瓷白底、墨色主操作，插画用淡奶油和灰褐做点缀。 |
| [蓝色主题](08-theme-blue.png) | 雾蓝底、墨蓝文字、钴蓝操作与同色系插画。 |

记录左侧是按类别绘制的小插画封面，随主题换色。记录信息下方显示彩色的照片缩略图及对应的 PDF、Word、Excel 文件图标。无附件时省略预览行。AI 卡片延用 A 版左图右文和底部三按钮的构造，悬浮导航、独立加号和列表工具保持同一布局。

本轮为静态概念稿。Excel 图标为设计示意，导入支持待实现。[主题 Prompt 日志](../../docs/prompts/2026-11-25-011.md)

## 浅色修订稿

[查看修订稿](04-refined-light.png)。以 C 的浅色布局为底稿，把 A 版「AI 智能填写」中拿着纸张的学生改绘为同色系插画。

- 「记录」和「我的」放进留有四周空隙的悬浮胶囊导航。右下使用独立的圆形「＋」按钮，点按进入新建记录，可访问名称为「新增记录」。
- 「多选」放到搜索框下方与「筛选」并排，保留文字标签及长按记录的入口。窄屏可将状态标签与工具分行。
- 每页使用白 `#FFFFFF`、墨黑 `#222034`、深紫 `#553CC2` 三种基础色，用文字和描边表达归档状态。图中的浅紫过渡是渲染效果，配色以这三个设计色值为准。

两屏为同一轮概念预览，识别按钮的启用和发送确认遵循 [产品规范](../../docs/PRODUCT_SPEC.md)。完整提示词见 [修订 Prompt 日志](../../docs/prompts/2026-11-25-009.md)。

## 最初三套方案

每套用相同的三条示例记录对比「记录」与「新建记录」。图片由内置生图生成，完整提示词见 [Prompt 日志](../../docs/prompts/2026-11-25-008.md)。

| 方向 | 界面特点 | 适合的取舍 |
| --- | --- | --- |
| [A · 深色档案](01-midnight-archive.png) | 墨紫背景和哑光卡片，琥珀色标记待补证明，紫色突出主要操作。 | 适合做暗色主题。元数据和浅紫按钮的字色需要单独核对对比度。 |
| [B · 插画手账](02-campus-editorial.png) | 奶油白、亮紫和少量黄色，档案袋插画与卡片色条增加辨识度。 | 适合更活泼的校园风格。把插画收在欢迎页或空状态，能为有内容的列表留出更多空间。 |
| [C · 浅色极简](03-light-minimal.png) | 冷白底、深靛色主操作、统一的状态标签和成组表单。 | 适合作为默认界面。列表容易扫读，手动填写入口清楚，AI 区块居于次要视觉层级。 |

建议用 C 做默认界面，借用 B 的小插画丰富空状态。列表优先展示名称、日期和证明状态，有附件时显示一张小缩略图或文件类别。表单重点保留名称、类别和保存按钮，其余按现有流程填写。

图片中的示例记录为虚构。B 稿的播放图标是生成误差，应用附件类型为照片、PDF 和 Word。A 和 C 稿的待补证明条目带有易误读的文档图标，落地时这一状态仅用类别图标。日期选择、AI 文本输入、发送确认及其他操作以 [产品规范](../../docs/PRODUCT_SPEC.md) 为准。
