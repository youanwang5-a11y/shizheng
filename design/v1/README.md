## 交互约定

底部只有记录和我的。“我的”页面分别设置“AI记录”和“AI设置”两个同级入口：AI记录用于输入活动描述、选择受支持的材料并生成草稿，复用19—21流程；AI设置仅负责启用开关、接口地址、Key、模型及连接测试，不作为进入AI导入的功能入口。AI默认关闭；关闭或未配置时，“我的”仍保留AI记录这一发现入口，点击显示启用/配置提示，用户主动选择去配置，完成后可返回AI记录继续操作。记录页中的快捷AI操作只在启用后出现。图片、PDF、Word混合附件导入后复制到应用内部存储。

新建记录必填名称、类别、时间。基本信息页以“保存记录”为主要操作，以“补充信息与证明（可选）”为次要操作，不把“下一步”作为必须完成的流程。没有材料也可直接保存，标记待补证明，以后从详情页编辑或添加证明。可选补充页包含单位、结果、备注与附件，不上传附件也能保存。编辑复用已填充的新增表单。单日/时间段切换决定日期字段；类别和级别为选项，学期可手动修改。

保存成功返回详情并提示“已保存”；有附件为已归档，没有附件为待补证明。新增附件后更新状态，删除最后一个附件后回到待补证明。删除记录与删除附件分别确认；删除记录提示会同时删除应用内的该记录附件，不删除最初导入的外部源文件。改名使用短文本对话框，照片排序在编辑证明列表中完成。

导出仅预留程序接口，当前不展示不可用的导出按钮。备份包含记录及原始附件，不包含API Key。恢复替换当前数据为本稿提案，实施前允许用户调整为合并方式。创建备份通过系统位置选择器选择保存位置，恢复通过系统文件选择器选择备份。

AI草稿必须由用户核对后保存；缺失字段留空，不擅自补全，日期年份不明确时要求确认。未选模型时不可测试成功，真实成功状态需要接口请求验证。发送前确认展示接收服务和发送范围。连接失败不影响本地功能。

## 生图误差与后续待补

2026-11-24用户反馈已确认：总体交互方向可用，UI美化延后；新建记录直接保存为主要操作，补充材料为可选；“我的”增加独立“AI记录”入口，与“AI设置”同级。现有图片保留作初稿，图02第05屏的主按钮和图04第14屏的菜单以后续这些规则为准。

这5张是主要流程概念稿，并未逐张展示全部系统选择器、权限、加载与错误状态。开发时应补齐：日期/时间段选择、必填校验、搜索无结果、保存成功、文件导入失败/进度、外部Word应用缺失、附件/记录删除确认、附件改名排序、备份失败及恢复完成、AI生成中/取消/模型不支持附件等状态；不据此声称所有交互已经定稿。

以以下规则覆盖生图中的冲突：

- 图01待补证明记录旁出现的场景图为生成误差，正式列表无附件时只显示类别图标，有附件时才显示真实证明缩略图。
- 图02第08屏有附件却标待补证明属于误差，应为已归档或隐藏状态标签。
- 图04备份成功后“上次备份”应更新为完成时间，不能仍显示“尚未备份”。
- 图05第21屏级别、单位、结果旁的必填星号为误差，这些字段均可选。
- 图05第18屏模型为空而显示连接成功属于独立状态示意冲突，实际须填写有效配置并测试成功才显示。
- 各图手机框、顶栏颜色、字号和图标存在差别；最终开发统一，建议采用浅色顶栏、青绿色操作色、橙色待补证明标签。

后续细化界面时落实以上已确认流程，并统一视觉样式。
