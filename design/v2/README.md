# 修改版概念图 v2

这些概念图对应首版讨论。当前版本支持首次欢迎、学年导出和记录多选，AI 填写位于新增页。交互以 [产品规范](../../docs/PRODUCT_SPEC.md) 为准。

使用内置image_gen生成。完整提示词见generation-prompts.txt。视觉仍为讨论稿，后续统一美化。原v1未受影响的页面继续参考，本次三张图替代新建、我的和AI使用流程。

- 01-optional-evidence.png：01基本信息直接保存；02补充信息与证明全部可选；03无证明保存后显示待补证明。02与03是不同保存分支：03演示从01直接保存，没有填写02的单位、结果。
- 02-ai-entries.png：04我的中AI记录和AI设置同级；05已配置时进入AI记录使用；06设置只负责配置。04的未启用与05/06的已启用是不同状态，非同一时刻的连续截图。
- 03-ai-flow.png：07未启用点击AI记录的提示；08发送范围确认；09草稿核对；10用户确认保存后变为普通记录。有附件的草稿在最终保存前不算正式归档，图09的已归档标签应理解为“已附证明”，开发时改用后者或不显示状态标签。

不增加账号、学号、个人资料、消息通知。AI设置保存后返回来源页面，不主动跳转到AI导入；从AI记录的配置提示主动去配置时保留返回上下文。AI不配置不影响本地记录功能。未附证明也能生成、核对并保存AI草稿；仅名称、类别、时间必填。

AI提供的日期等不明确时留空并要求核对；材料为用户实际导入的附件，不是AI生成的证明。图片文字、图标和布局为概念参考，最终遵循交互规则。
